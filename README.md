# جاسوس‌خانه فرخی‌ها

بازی جاسوس مخصوص خانواده فرخی‌ها (فارسی، بدون نیاز به اینترنت بعد از اولین باز شدن).

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا نسخه آنلاین (GitHub Pages) را باز کنید.

## ساخت APK
۱. همه فایل‌های این پوشه را در یک repository گیت‌هاب آپلود کنید.
۲. از Settings ← Pages شاخه main را فعال کنید تا آدرس https بگیرید.
۳. به pwabuilder.com بروید، آدرس را وارد کنید، Package for stores ← Android را بزنید و APK را دانلود کنید.
